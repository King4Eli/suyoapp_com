    -> found and fixed a real bug: cacheStorage.getCurrentUserProfile() and .getProducts() (llstorage.ts) unconditionally wiped their memory + AsyncStorage cache to null whenever the request came back empty -- which is exactly what happened on a network failure/offline blip too (xxa__http_requests returns null/false for that case).
